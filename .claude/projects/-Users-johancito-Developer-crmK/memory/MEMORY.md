# Elibry — Project Memory Index

This directory holds persistent memory files for the Elibry project.
Each file is self-contained and prefixed with its topic area.

## Memory files

| File                                                 | Description                                                    |
| ---------------------------------------------------- | -------------------------------------------------------------- |
| [project_sprint_state.md](./project_sprint_state.md) | Current sprint completion state and remaining backlog priority |

## Usage

Before starting any sprint or planning session, read `project_sprint_state.md`
to confirm what has already been shipped and which backlog items are highest
priority. Update that file at the end of each sprint with the new completed
work and any changes to the backlog ordering.
